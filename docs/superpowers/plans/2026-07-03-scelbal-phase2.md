# SCELBAL Phase 2 Implementation Plan — b8008_basic (boot-to-BASIC)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Power-on → BASIC prompt. `MON` statement drops to the monitor (our CALL -151); monitor `G <warm>` returns with the program intact (our 3D0G).

**Architecture:** New project `projects/b8008_basic`, same RTL, inverted map: RAM 0x0000-0x0FFF (page 0 = vectors + BRAM-init boot-JMP + monitor scratch; 0x0100-0x0BFF user programs ~2.75KB; 0x0C00-0x0FFF SCELBAL variable pages), ROM 0x1000-0x3FFF (monitor reassembled at 0x1000, SCELBAL at 0x1800+, init images inline). Bootstrap RST-0 jam lands on the BRAM-initialized `JMP SCELBAL_COLD` at RAM[0]. RST vectors are writable RAM — forwarding slots retire in this personality.

**Tech Stack:** unchanged (GHDL via make, AS assembler, emu8008 oracle, monitor_scelbal_tb pattern with RAM_INIT_FILE plumbing from Phase 1).

## Global Constraints

- Spec: `docs/superpowers/specs/2026-07-03-scelbal-design.md` (Phase 2 section).
- Minimal-divergence rule for SCELBAL body: ORG/EQU retargets + the MON keyword only; everything else stays byte-for-byte Loos (the VCF changelog discipline).
- Page 0 layout must keep 0x0000-0x003F (vectors + boot JMP) and monitor scratch OUT of every SCELBAL-writable region — reset must always work.
- b8008_monitor project stays untouched and buildable (two personalities, one RTL).
- Commit-only-proven for the final bitstream; oracle + monitor_scelbal_tb-style sim first.

### Task 1: Memory-map plan of record (page 0 ledger)

**Files:**
- Create: `projects/b8008_basic/MEMORY_MAP.md`

Exact page-0 ledger (single source of truth for every later EQU):

```
0x0000-0x0002  boot JMP SCELBAL_COLD   (BRAM init; rewritten by nothing)
0x0003-0x0007  reserved (zeros)
0x0008-0x003F  RST 1-7 vectors        (writable RAM - programs install directly)
0x0040-0x00BF  monitor scratch        (CMD_LEN/CMD_BUF/DUMP/HEX-loader vars,
                                       trampoline at 0x00B0)
0x00C0-0x00FF  reserved
0x0100-0x0BFF  user BASIC program buffer   (BGNPGRAM=0x01, ENDPGRAM=0x0C)
0x0C00-0x0FFF  OLDPG1=0x0C00 OLDPG26=0x0D00 OLDPG27=0x0E00 OLDPG57=0x0F00
0x1000-0x17FF  ROM: monitor (reassembled ORG 0x1000)
0x1800-0x3FFF  ROM: SCELBAL (reassembled ORG 0x1800; images inline)
```
